# SUHITA D - Portfolio Website

A modern, clean, and responsive personal portfolio website built with pure HTML, CSS, and JavaScript.

![Portfolio Preview](assets/images/preview.png)

## 🌟 Features

### UI/UX
- ✅ Clean minimal glassmorphism design
- ✅ Professional gradient color palette
- ✅ Mobile-first responsive layout
- ✅ Smooth scrolling navigation
- ✅ Dark/Light mode toggle with persistence
- ✅ Hover effects and animations

### JavaScript Features
- ✅ Preloader animation
- ✅ Typing text animation
- ✅ Scroll reveal animations
- ✅ Active navbar highlighting
- ✅ Animated skill progress bars
- ✅ Animated counters
- ✅ Form validation
- ✅ Back-to-top button

### Sections
- 🏠 **Hero** - Name, role, tagline, CTA buttons, stats
- 👤 **About** - Personal introduction, professional info, goals
- 💻 **Skills** - Technical skills with progress bars, soft skills
- 📂 **Projects** - Featured project showcase
- 📄 **Resume** - Education, internships, achievements, certifications
- 📧 **Contact** - Contact form and social links
- 📜 **Footer** - Copyright and social icons

## 🚀 Getting Started

### Local Development
1. Clone or download this repository
2. Open `index.html` in your browser
3. Or use a local server like Live Server (VS Code extension)

### Customization
1. **Personal Info**: Edit the content in `index.html`
2. **Colors**: Modify CSS variables in `css/style.css` under `:root`
3. **Animations**: Adjust timing in `js/script.js`

## 🌐 Deployment

### GitHub Pages
1. Push code to GitHub repository
2. Go to Settings → Pages
3. Select source branch (main)
4. Your site will be live at `https://username.github.io/repository-name`

### Netlify
1. Connect your GitHub repository
2. Set build command: (leave empty)
3. Set publish directory: `/`
4. Deploy!
